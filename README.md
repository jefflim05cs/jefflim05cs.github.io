# jefflim05cs.github.io

Personal portfolio of Jeff Lim, published with GitHub Pages at https://jefflim05cs.github.io.

A static site with no build step and no dependencies. Open `index.html` in a browser to run it locally.

## Structure
- `index.html`: page content and sections
- `css/style.css`: styles. The palette, fonts and spacing are tokens at the top of the file.
- `js/sigil.js`: generative hex sigils. The same seed always produces the same sigil.
- `js/skyline.js`: the flat-vector city band, generated from a seed
- `js/main.js`: intro sequence, scroll reveals, honeycomb, light/dark theme
- `licenses/`: font licenses (SIL Open Font License 1.1)

## Palette
