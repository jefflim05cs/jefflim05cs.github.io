# Font licenses

This site uses two typefaces, both licensed under the **SIL Open Font License, Version 1.1 (OFL-1.1)**.
The full license texts are in this folder. They were taken from the official Google Fonts repository.

| Family | Use | Designer | Copyright | License file |
|---|---|---|---|---|
| Archivo | Headlines (expanded width) and body text | Omnibus-Type | © 2020 The Archivo Project Authors | `Archivo-OFL.txt` |
| Space Mono | Labels, numbers, code | Colophon Foundry | © 2016 The Space Mono Project Authors | `Space-Mono-OFL.txt` |

The fonts are currently loaded from Google Fonts, so no font files are redistributed here.
If they're self-hosted later, keep each `*-OFL.txt` next to its font files.
Neither family has a Reserved Font Name, so subsetting them for the web is fine.
